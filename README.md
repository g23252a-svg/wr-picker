# WR Picker v8.3

와일드 리프트 드래프트에서 라인, 아군, 상대, 밴을 입력하면 **매일 자동 갱신되는** 랭크 구간별 통계와 라인전 상성, 전술 브리핑, 그리고 **내 실제 성과**를 함께 계산하는 설치형 웹 앱입니다.

## v8.3 개선 (전술 브리핑)

추천 카드마다 `▾ 전술 보기`를 누르면 운영·상성 정보가 펼쳐집니다.

- **이 판**: 라인 상대와의 상성, 파워 커브, 아군 연계, 상대 위협 — 엔진이 이 드래프트에서 실제로 계산한 값
- **이 챔은 / 운영 / 상성**: WildRiftFire 챔피언 가이드(139챔)에서 뽑은 요점. **전부 한글로 표시**합니다 — 영문 원문을 통째로 번역하면 오역 위험이 커서, 가이드에 반복 등장하는 표현만 골라 한글 전술 문장으로 변환합니다(요약 131/139, 운영 136/139). 매칭이 없으면 억지로 채우지 않고 비웁니다
- **콤보·아이템 수치는 담지 않습니다.** 패치마다 바뀌고 틀리면 실전에서 손해이므로, 원문 가이드로 바로 가는 링크를 제공합니다
- `scripts/fetch-guides.mjs` + 주간 워크플로로 자동 갱신합니다. 가이드 URL slug는 추측하지 않고 통계 payload가 알려주는 값을 씁니다(이름에서 만들면 틀립니다 — `Nunu & Willump` → `nunu-amp-willump`)

## v8.2 개선 (목표 설정 — 전 포지션 숙련)

분석 탭이 단기 승률만 보고 "약한 라인을 줄이세요"라고 조언했습니다. **모든 포지션을 잘하고 싶다**는 목표와는 정면으로 충돌합니다. 앱이 목표를 알도록 고쳤습니다.

- **목표 설정**: 설정 화면에 `전 포지션 숙련`(기본) / `승률 우선` 선택을 추가했습니다. 추천 점수 계산은 동일하고 **분석 탭의 조언만** 달라집니다
  - 전 포지션 숙련: 라인을 버리라고 하지 않고, **그 라인 안에서 무엇을 남기고 무엇을 정리할지** 짚어줍니다 — "원딜은 라인이 아니라 챔 문제입니다"
  - 승률 우선: 기존처럼 잘 되는 라인에 집중하라고 안내합니다
- **라인별 성장과 주력 정리 카드**: 라인마다 전반 → 후반 승률 추이(↑↓)와 유지/정리 후보 챔을 한 화면에 보여줍니다. 실사용 데이터 예: 탑 45%→70%↑(말파이트 100% 유지 / 쉔 33% 정리), 원딜(제리 71% 유지 / 스몰더 0% 정리)
- 한국어 조사 처리기(은/는, 이/가, 을/를)를 추가해 라인 이름 뒤 조사가 자연스럽게 붙습니다

## v8.1 개선 (라인전 사거리 · 팀 변수 보정)

- **라인전 사거리 축 추가**: 와일드리프트는 라인전이 승패를 크게 좌우하는데, 엔진이 챔피언을 근접/원거리 둘로만 봐서 **같은 원거리끼리는 전부 동일 취급**했습니다. 오리아나(장거리 공 배치) 상대로 케넨(단거리)이 겪는 손해를 인식하지 못한 원인입니다. 사거리 등급(장/보통/단)을 도입해 라인전 상성에 반영합니다 — 검증: 케넨 vs 오리아나 카운터 44(불리), 오리아나 vs 케넨 62(우위). 정확한 수치는 패치마다 바뀌므로 **방향이 확실한 챔만 등재**하고 나머지는 보통으로 둡니다
- **팀 문제 표시**: 트롤·잠수·역할 미준수로 진 판을 `⚠ 팀 문제`로 표시하면 **그 패배가 챔피언 평가에서 제외**됩니다(중립 처리). 승리는 표시해도 그대로 반영합니다. 자기 신고는 편향되기 쉬우므로 분석 탭에 **표시 비율을 그대로 노출**하고, 40%를 넘으면 경고합니다
- **원딜 서폿 변수 분석**: 아군 픽에 엔첸터·탱커가 있었는지로 봇 라인 변수를 **객관적으로** 측정합니다(자기 신고 아님). 실사용 데이터에서 서폿류 있음 55% vs 없음 20%로 갈렸습니다

## v8.0 개선 (숙련도는 실적으로 결정된다)

설계 원칙: **탐색은 막지 않고, 실패가 쌓인 것만 깎는다.**

- **수동 숙련도 → 사전값(prior)으로 격하**: 예전에는 설정에서 정한 값이 실제 성적을 완전히 덮어썼습니다. 13판 38%인 챔이 계속 70점으로 추천되던 원인입니다. 이제 판이 쌓일수록 실측으로 수렴합니다(4판이면 절반, 12판이면 75%가 실측). 예: 케넨 등록 70 → **적용 53**
- **KDA를 성과 신호로 사용**: `(K+A)/D`를 포화 함수로 환산해 성과 등급과 함께 반영합니다. **승리와 개인 성과는 각각 독립적인 플러스 신호**로 다룹니다 — 이긴 판은 성과가 나빠도 깎이지 않고(하한 보장), *졌지만 12/2/8*은 중립 위(0.61)로 올라가며, 지고 성과도 나쁠 때만(0.20) 내려갑니다
- **첫 픽 감점 제거**: 메타가 좋은 새 챔은 그대로 상위에 올라옵니다. 시도를 막으면 주력이 늘지 않고 현재 챔폭에 갇힙니다. `첫 픽` 배지는 정보로만 유지하고, 손해는 *해본 뒤 성과가 나빴다*는 실측으로만 반영합니다
- **조정 내역 투명화**: 추천 카드에 `숙련 70→53` 배지, 설정 화면에 `→ 실적 53 (13판)` 표시
- **자동 백업 복구**: 실패 원인을 구분해 표시하고(파일 없음 / 권한 / 잠김), 재연결이 실패하면 **새 파일 지정**으로 넘어갑니다. 예전에는 모든 실패가 "권한 끊김"으로 표시되고 옛 파일만 재시도해 빠져나올 수 없었습니다

## v7.3 개선 (전적 보호)

과거 전적이 조용히 사라질 수 있는 경로를 모두 막았습니다.

- **복원은 덮어쓰지 않고 합칩니다**: 예전에는 백업을 불러오면 현재 기록을 통째로 교체해, 오래된 백업을 복원하면 그 뒤에 쌓인 판이 전부 사라졌습니다. 이제 판 시각을 키로 병합하며 중복은 건너뜁니다(성과·KDA는 기록된 쪽을 남김)
- **되돌리기**: 복원·전체삭제 직전 상태를 스냅샷으로 남겨 실수로 지워도 복구합니다. 전체삭제는 2단계 확인을 거칩니다
- **알 수 없는 챔피언도 보존**: 챔피언이 이름 변경·삭제되면 해당 판이 마이그레이션에서 영구히 버려졌습니다. 이제 원본 값을 `pickRaw`로 남겨 판수를 지키고 나중에 복구할 수 있습니다
- **저장 실패를 알립니다**: 저장 공간이 가득 찼거나 시크릿 모드일 때 기록이 조용히 유실됐습니다. 이제 상단 경고와 함께 즉시 백업을 유도합니다
- 시드 전적도 덮어쓰기가 아닌 병합으로 적재합니다

## v7.2 개선 (자동 백업)

- **자동 백업**: 전적이 브라우저 저장소에만 남아 기기를 벗어나지 못하고, 백업도 매번 수동이라 실제로는 잘 안 하게 되는 문제를 고칩니다. 파일을 **한 번만 지정하면** 이후 판을 기록할 때마다 같은 파일에 자동 저장됩니다(File System Access API, 데스크톱 Chrome·Edge). 브라우저를 다시 열어 권한이 초기화되면 `다시 연결` 버튼으로 복구하며, 그동안에도 앱 동작에는 영향이 없습니다
- 미지원 브라우저(모바일·Safari 등)를 위해 **복사** 버튼을 추가했습니다 — 백업 JSON을 클립보드로 바로 가져갑니다

## v7.0–7.1 개선 (개인 성과 학습 · 분석 탭)

실사용 전적 102판을 분석해 나온 문제를 고칩니다.

- **개인 성과 기록(MVP·SVP·KDA)**: 승패는 팀 단위 결과라 10판 규모에선 거의 노이즈입니다. "졌지만 내가 SVP"는 픽이 맞았다는 강한 증거이므로 승패와 분리해 기록하고, 숙련도 학습에 이 신호를 씁니다
- **숙련도 산식 교정**: 기존엔 판수가 가산점이라 *많이 지고 있는 챔도 숙련도가 높게* 나왔습니다(실측: 13판 38% 챔이 54점). 이제 판수는 추정의 확신도로만 쓰고 실제 성과가 점수를 결정합니다(같은 챔 → 48점)
- **메타 중심 모드의 숙련 반영**: 기존엔 숙련 가중치가 **0**이라 엔진이 매판 새 챔을 추천했습니다. 실측상 처음 잡는 챔은 2~3판째보다 승률이 크게 낮은데, 이 손해를 사용자가 그대로 떠안고 있었습니다. 이제 메타가 주도하되(35%) 익숙한 픽이 동점을 깹니다
- **첫 픽 경고**: 한 번도 안 해본 챔에 `첫 픽` 배지와 소폭 감점(승률 약 2%p 우위가 있어야 추천). 좋은 신규 픽은 여전히 올라옵니다
- **자기 측정**: 전적 화면에 엔진 버전별 승률을 추가해 "패치 후 나빠졌나"를 인상이 아니라 데이터로 확인합니다
- **분석 탭**: 전적 화면이 `기록` / `분석` 두 탭으로 나뉩니다. 분석 탭은 이항검정으로 **최근 부진이 정상 변동인지 유의한 하락인지 먼저 판정**하고(10판 30%는 대개 정상), 실행 가능한 개선점을 표본 크기와 함께 제시합니다 — 입력 성실도별 승률, 챔피언 경험도, 라인 집중도, 하루 N판째 피로도, 챔폭 점검. 8판 미만 구간은 흐리게 표시해 단정하지 않습니다

## v6.1 개선 (랭크 구간 선택 · 밴 추천)

- **랭크 구간 선택**: Diamond+ / Master+ / Challenger 통계를 탭 한 번으로 전환합니다. 선택은 저장되어 다음 방문에도 유지되고, 구간 전체가 payload에 담겨 있어 재요청 없이 즉시 바뀝니다
- **밴 추천**: 표본 보정 승률 + 픽/밴 존재감 + 상승 추세로 위협 점수를 계산해 상위 3챔을 제안합니다. 내 라인에서 만나는 챔은 가중하고, 내 주력(수동 숙련도 또는 전적 기반)을 카운터치는 챔은 가산합니다. 제안을 탭하면 바로 밴 목록에 들어갑니다
- **추세 기준선 버그 수정**: 구간 전환 시 추세를 반드시 같은 구간끼리 비교합니다. 이전에는 Master+ 현재치가 Diamond+ 기준선과 비교되어 '구간 차이'가 '패치 변화'로 표시될 수 있었습니다
- **원격 데이터 신뢰 경계**: `data/latest.json`은 서드파티 페이지에서 자동 수집되므로, 앱이 채택 전 전체를 정규화합니다(필드 형식·범위 검증, 앱 DB에 없는 챔피언 제거, 라벨/키 화이트리스트). 파이프라인에서도 같은 검증을 수행해 오염 데이터가 커밋되지 않게 막습니다
- 구간 선택기를 DOM API로 조립하고, 버튼 재생성 시 키보드 포커스를 복원합니다

## v6.0 개선 (상성 엔진 개편 — 실전 오추천 수정)

실사용 보고에서 출발: 미드에서 상대가 **아리**인데 **탈론**이 추천됨(라인 삭제 수준의 역상성). 원인은 클래스 매트릭스의 '암살자>메이지 +2'가 아리처럼 **기동기+CC를 가진 메이지에겐 정반대**라는 것.

- **기동·셀프피어 조정**: 암살자↔물몸 원거리 상성에서 상대의 도주기(mob)·하드CC·점착CC 보유량만큼 클래스 우위를 상쇄/역전. 부동 메이지(신드라·직스) 상대 암살자 우위는 유지, 아리류 상대는 역카운터로 판정
- **아리 KIT 교정**: 궁 3연속 이동을 `mob:2`로 반영 (기존 미인식)
- **'파고들어 응징' 게이팅**: 기동성 2 이상 상대는 파고들어도 못 잡음 — 보너스 대신 감점
- **유명 상성(PAIR) 확장**: 3항목 → 미드(아리>탈론·제드·카타리나, 피즈>아리, 갈리오>AP암살자, 카사딘>부동AP)·서폿(모르가나>그랩류)·탑(피오라>방템탱커) 등 방향이 확실한 정설만 보수적으로 등재
- **회귀 테스트**: PAIR/KIT 키가 로스터에 실존하는지 검증 + 아리>탈론 등재·기동 게이팅 존재를 스모크에 고정

## v5.1 개선 (상성 입력 UX · 무통계 보정)

- **라인 상대 지정 발견성 개선**: 상대 칩 이름에 흐린 🎯를 상시 표시해 탭 가능함을 알리고, 지정하면 진해지며 칩이 강조됩니다. 상대 픽이 있는 동안 "🎯 상대 칩 이름을 탭하면 내 라인 상대를 지정합니다" 안내를 계속 노출합니다(기존엔 드래프트가 비었을 때만 보여 발견이 어려웠음)
- **통계 없는 역할 보정**: 역할 통계가 없는 픽을 중립 50이 아니라 '평균 승률 + 존재감 0'(≈48.5)으로 평가합니다. 데이터 없는 픽이 측정된 평균 이하 챔피언을 밀어내던 역전을 제거

## v5.0 핵심 개선 (자동 데이터 파이프라인)

- **스탯 자동 갱신**: GitHub Actions가 매일 WildRiftFire 통계를 받아 커밋합니다. 수동 갱신이 더 이상 필요하지 않습니다
- **런타임 데이터 로딩**: 앱이 `data/latest.json`을 우선 사용하고, 실패하면 캐시 → 번들 스냅샷 순으로 폴백합니다. 앱을 다시 배포하지 않아도 통계가 최신으로 유지됩니다
- **랭크 구간 3종 수집**: Diamond+ / Master+ / Challenger 전체를 저장합니다 (UI 선택기는 다음 패치)
- **일자별 아카이브**: `data/history/<날짜>.json`이 쌓이며 추세 계산의 기준선이 됩니다
- 업스트림의 주 라인 플래그(`main`)와 공식 티어(`tier`)를 함께 수집해 주 라인 판정을 추정이 아닌 실제 값으로 대체
- 서비스 워커가 통계 경로만 네트워크 우선으로 처리해 캐시된 옛 데이터가 고정되는 문제 제거
- 스모크 테스트를 특정 수치가 아닌 불변식 검증으로 전환해 매일 갱신돼도 깨지지 않음

## v4.2 개선 (패치 추세 엔진)

- 직전 스냅샷을 함께 내장해 역할별 승률 **추세(▲/▼ %p)** 를 계산·표시
- 추세를 표본 신뢰도로 감쇠해 메타 축에 소폭 반영(±2.5점 한도) — `패치 상승세`/`패치 하락세` 배지
- 추천 카드·검색 드롭다운·지금 픽 요약에 추세 정보 노출
- 패치 라벨·데이터 상태줄이 스냅샷 메타를 그대로 따라가도록 동적화

- 조합·카운터·메타·숙련 점수를 0–100 가중평균으로 제공
- 역할 통계가 있는 비주류 포지션까지 자동 후보에 포함
- 드래프트 자동 저장, 40단계 실행취소/다시실행, URL 공유
- 다크/라이트 테마와 모바일·태블릿·데스크톱 반응형 2열 UI
- 키보드 검색 탐색, 포커스 트랩, 스크린리더 상태 안내, 확대 허용
- JSON 파일 기반 전적 백업/복원과 안전한 데이터 마이그레이션
- 설치 프롬프트, 오프라인 앱 셸, 새 버전 업데이트 알림

## 실행

별도 빌드 없이 정적 서버로 실행합니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. `file://`로도 핵심 기능은 동작하지만 서비스 워커와 설치 기능은 HTTP(S)에서만 사용할 수 있습니다.

## 데이터 파이프라인

```bash
node scripts/fetch-stats.mjs
```

WildRiftFire 통계 페이지에 인라인된 JSON 페이로드를 받아 세 곳에 씁니다.

| 산출물 | 용도 |
| --- | --- |
| `data/latest.json` | 앱이 실행 시 받아오는 최신 통계 (랭크 구간 3종 + 추세 기준선) |
| `data/history/<날짜>.json` | 업스트림 갱신일 기준 아카이브, 추세 기준선의 출처 |
| `stats.js` | 앱 셸에 번들되는 오프라인 폴백 (Diamond+) |

챔피언 가이드는 따로 수집합니다(패치 때나 바뀌므로 주 1회).

```bash
node scripts/fetch-guides.mjs
```

`data/guides.json`에 챔피언별 한글 전술 요점·카운터·궁합을 씁니다. `--from <디렉터리>`로 미리 받아둔 HTML을 파싱할 수 있고, 수집 성공률이 50% 미만이면 기존 파일을 덮지 않습니다(사이트 구조 변경 시 데이터 보호). `.github/workflows/update-guides.yml`이 매주 월요일에 실행합니다.

`--from <파일>`로 저장된 페이지를 파싱하거나 `--dry-run`으로 쓰기 없이 점검할 수 있습니다. 챔피언 DB에 없는 신규 챔피언이 나오면 해당 행만 건너뛰고 종료 코드 2와 함께 이름을 출력하며, CI는 이를 경고로 표시하되 나머지 갱신은 계속 진행합니다.

`.github/workflows/update-stats.yml`이 매일 04:20 UTC(13:20 KST)에 이 스크립트를 실행하고, 스모크 테스트를 통과하며 실제 변경이 있을 때만 커밋합니다. Actions 탭에서 수동 실행도 가능합니다.

## 데이터 메모

통계 출처는 중국 서버(lolm.qq.com) 랭크 데이터이며, 티어 등급은 WildRiftFire 티어 리스트를 따릅니다. 앱 화면에 패치·지역·랭크 구간·스냅샷 날짜를 표시하고, 통계가 없는 챔피언/역할은 메타 축을 중립으로 처리합니다. 추세는 양쪽 스냅샷 픽률이 1% 이상일 때만 계산합니다.

`stats.js`와 `data/`는 생성 파일이므로 직접 수정하지 말고 파이프라인을 다시 실행하세요.
