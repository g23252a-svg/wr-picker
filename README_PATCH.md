# WR Picker v13.0.0 대규모 개선 패치

전체 기능과 실행·검증 방법은 [README.md](README.md)를 참고하세요.

실사용 전적 **242판**(2026-07-03 ~ 09-04)으로 검증했습니다. v12 진단 카드를 이 데이터에 걸었더니 두 가지 결함이 드러났습니다.

## 1. 고정 창이 슬럼프를 희석했다

v12의 비교 창은 `전체의 20%` 고정(242판이면 40판)이었습니다. 실제 바닥은 **최근 30판 37%**인데, 40판으로 뭉개면 **45%**가 됩니다 — 슬럼프를 찾는 카드가 슬럼프를 지워서 보여준 셈입니다.

- 10·12·16·20·24·30·40판을 훑어 신호가 가장 강한 창을 고릅니다
- **훑은 개수만큼 p를 보정합니다.** 유의성을 만드는 장치가 아닙니다 — 보정 후 p는 0.079 → 0.555로 *올라가고*, 카드는 그대로 "우연 범위"라고 말합니다. 달라진 건 보고하는 숫자가 실제 폼과 맞는다는 것뿐입니다
- 창별 승률 곡선을 그려 어디서 꺾였는지 보여줍니다

## 2. 성과 등급을 모아만 두고 진단에 안 썼다

v7부터 판마다 MVP/SVP/잘함/보통/부진을 받아온 이유가 **팀운과 내 플레이를 가르기 위해서**인데, 진단 카드는 승률만 봤습니다.

교란이 큽니다 — 성과는 승패와 강하게 붙어 있습니다(242판에서 이긴 판 0.63 vs 진 판 0.46, **p=0.0001**). 전체 평균만 비교하면 "연패 중이니 성과도 낮다"는 동어반복이 되고, **v13 초안이 실제로 그 함정에 빠져 "성과 하락(p=0.041)"이라고 단정했습니다.**

- 판정은 **결과가 같은 판끼리만** 비교합니다(다중 비교 2건 보정). 같은 데이터로 다시 재면 진 판 0.45→0.47, 이긴 판 0.62→0.68 — **둘 다 안 떨어졌습니다**
- 성과 점수는 **원등급**을 씁니다. `perfValue()`는 설계상 승패(0.74/0.26)를 섞어서, 그걸 쓰면 승률을 두 번 재게 됩니다
- 전체 평균은 맥락으로만 싣고 판정에서 뺍니다

## 검증

| | v12.1 | v13.0 |
| --- | --- | --- |
| 보고하는 최근 폼 | 45% (40판 고정) | **37% (30판, 실제 바닥)** |
| 창 탐색 다중비교 보정 | 없음 | **창 7개만큼** |
| "실력이 떨어진 건가"에 답하는가 | 못 함 | **결과별 성과 비교로 답함** |
| 242판 재채점 시 점수가 달라진 판 | — | **0판 / 242판** |

**엔진 점수는 한 줄도 안 건드렸습니다.** 돌연변이 6종(창 보정 제거 / need 불일치 / 동률 처리 제거 / 성과에 승패 섞기 / 교란된 총평균으로 판정 / 소표본 기권 제거)을 심어 새 테스트가 전부 잡는 것을 확인했습니다.

기존 전적·챔폭·가중치는 그대로 유지되며 별도 마이그레이션이 필요 없습니다.

서비스 워커 캐시로 이전 버전이 보이면 화면 상단의 업데이트 알림을 누르거나 한 번 강력 새로고침하세요.
