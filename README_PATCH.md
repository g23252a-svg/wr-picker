## 분석 탭의 유일한 확신을 드래프트 화면이 모르고 있었다

실사용 258판에서 통계적으로 뒷받침되는 조언은 하나뿐입니다 — *처음 잡는 챔을 줄이세요*. 처음 잡는 챔 **40% (47판)** vs 2~3판째 **65% (62판)**, 우연일 확률 1%. v9부터 분석 탭에 있었지만, 챔을 고르는 화면에는 `첫 픽` 두 글자와 최대 −6 감점뿐이었습니다.

## 감점을 키우면 되지 않나 — 재봤고, 아닙니다

첫 픽 감점을 실측 격차로 바꾸는 설계 4종을 prequential 순위 일치도로 비교했습니다. 현재 0.5693 대비 0.5636 ~ 0.5769, **전부 오차(±0.036) 안**입니다. 엔진 1순위가 첫 픽인 경우가 **228판 중 8판(4%)**뿐이라, 첫 픽은 엔진이 미는 게 아니라 사용자가 고르는 것이고 감점은 그 선택을 못 바꿉니다. 점수는 그대로 둡니다.

## 대신 고르는 순간에 본인 숫자를 보여줍니다

- 첫 픽 배지: **`첫 픽 · 내 첫 픽 승률 40% vs 익숙한 챔 65%`** (마우스 올리면 판수·우연일 확률)
- **유의할 때만** (양쪽 8판 이상, 격차 양수, p ≤ 0.05). 아니면 이전 배지 그대로
- 분석 탭과 같은 버킷(0판 / 1~2판 / 3판+)
- 전적이 바뀌면 다시 계산
