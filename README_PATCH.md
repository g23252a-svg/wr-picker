# WR Picker v19.0.0 패치

전체 기능과 실행·검증 방법은 [README.md](README.md)를 참고하세요.

새 전적은 없어서, 게임이 **7.2e → 7.3 → 7.3a**로 넘어간 동안 앱이 깨진 데를 찾았습니다. 일일 통계 **71일치**와 실사용 **271판**으로 쟀습니다. 두 군데서 앱이 **이름과 다른 것을 재고** 있었습니다.

## 1. "직전 패치 대비"가 실은 '어제 대비'였다

| 잰 것 (71일, 다이아+) | 결과 |
| --- | --- |
| 같은 패치 안 하루 변화 → 다음 날 | 회귀계수 **−0.27** (11,151쌍) — 되돌아간다 |
| 앱 방식(×1.2 가산)의 다음 날 예측 오차 | **0.980** vs 오늘 승률 그대로 **0.337** |
| 진짜 패치 간 변화 vs 같은 패치 안 변화 | 분산 **3.8배** — 의미가 있다 |

노이즈에 거꾸로 베팅하면서 진짜 패치 변화는 안 보여줬습니다. 예: **말파이트(탑, 실사용 13판)는 7.3 대비 −4.0%p**인데 앱은 −0.44(배지 없음).

- 기준선 = **직전 패치 마지막 3일 평균**. 직전 패치가 없으면 추세를 비움
- 판 전체가 같이 뜬 몫은 뺌(7.3a는 평균 +0.39%p — 상승 배지 35:하락 6 → 17:12)
- 같은 패치 기준선은 원격·캐시·번들 어디서 와도 거부
- *"패치 상승세"* → **"7.3 대비 상승"** — 계속 오른다는 뜻이 아니므로
- **점수 반영 0.** 직전 패치 대비 변화가 이어지는 건 패치 첫 이틀뿐이고, 패치 전체로는 오히려 반대(−0.13 ± 0.007, 9,589쌍). 실전 205판 재채점에서도 영향 없음(0.5482 → 0.5483). 밴 추천의 추세 가산도 제거

## 2. 엔진 자기 검증이 7월 판을 10월 통계로 채점했다

| 메타 축 순위 일치도 (271판) | 값 | 자동 보정 발언권 |
| --- | --- | --- |
| 오늘 통계로 채점 (v18) | **0.544** (네 축 중 1위) | 106% |
| 그 판 당시 패치 통계로 채점 (v19) | **0.497** (동전던지기) | **100%** |

- 패치별 평균 통계 `data/by-patch.json`(8개 패치, 133KB)을 파이프라인이 매일 생성
- 자기 채점은 판마다 기록된 패치의 표로 바꿔 끼우고 끝나면 되돌림
- 성적표가 무엇으로 채점했는지 밝히고, 표를 못 받으면(오프라인) 경고

## 실제 추천 변화

실사용 271개 드래프트(오늘 통계, 실제 브라우저): **1순위 4판**(1·2위 근소차 자리바꿈), top3 순서 33판. 엔진이 더 잘 맞히게 된 게 아니라, **앱이 자기 자신에 대해 하던 거짓말**을 고친 것입니다.

v18의 숙련 가중 비교도 오늘 통계로 잰 것이었지만, 같은 통계 위의 상대 비교라 결론("전부 오차 안")은 그대로입니다.
