# WR Picker v12.1.0 대규모 개선 패치

전체 기능과 실행·검증 방법은 [README.md](README.md)를 참고하세요.

이번 패치의 주제는 **"요새 왜 지지?"에 앱이 답하게 만드는 것**입니다. 검증은 실사용 전적 199판(2026-07-03 ~ 08-12)으로 했습니다.

## v12.1 — 카드가 자기가 만든 가짜 신호를 띄웠다

v12.0을 실사용 218판에 걸자마자 카드가 딱 하나를 "달라진 것"으로 올렸습니다 — 팀 문제 표시 3% → 18%, 우연일 확률 0.2%. **카드가 만든 가짜 신호였습니다.** `팀 문제` 표시는 v8.1에 생긴 기능이라 그 전 판은 전부 0이고, 최근 구간과 비교하면 "급증"이 무조건 유의하게 나옵니다.

비교 항목마다 **그 값을 기록할 수 있었던 구간**으로 창을 좁히고(판에 남은 `modelVersion` 기준), 좁힌 뒤 표본이 모자라면 그 항목은 검정하지 않습니다. 수정 후 같은 항목은 10% → 18%로 유의하지 않게 내려가고 **"달라진 것: 없음"**이 됩니다.

## 슬럼프에 무엇이 달라졌는지 말하지 못했다

v11까지 분석 탭은 최근 10판이 정상 변동인지만 판정하고(그건 "왜"가 아닙니다), 나머지 카드는 전 기간을 뭉쳐 보여줬습니다. 연패 중에 알고 싶은 건 하나입니다 — **직전과 비교해 뭐가 달라졌는가.**

- 최근 20%(12~40판)와 그 이전을 같은 잣대로 놓고 **처음 잡는 챔 비율 · 상대 입력량 · 라인 상대 인지율 · 세션 길이 · 팀 문제 표시 · 라인 비중 · 현재 패치 전후**를 2표본 검정하고 **다중 비교를 보정**합니다
- **내가 바꿀 수 있는 것**(행동)과 **바깥에서 바뀐 것**(패치)을 갈라 보여줍니다 — 패치 탓을 픽 습관 탓으로 돌리지 않게
- 나빠진 것만 고르면 카드가 서사에 맞는 것만 보여주는 셈이라, **유의하지만 나쁜 방향이 아닌 변화도 같이** 올립니다
- 아무것도 안 달라졌으면 **그렇게 말합니다.** 슬럼프에 없는 원인을 만들어 붙이는 게 제일 나쁜 조언입니다

실사용 199판 결과: 최근 40판 48% vs 이전 159판 54%, **우연일 확률 46%**. 7개 항목 중 승률을 깎는 쪽으로 달라진 것은 **없었습니다**. 유일하게 유의한 변화는 처음 잡는 챔 비율이 25% → 5%로 **줄어든 것**이었습니다.

## "아직 판단할 수 없습니다"에 기한이 없었다

v11 이후 앱이 제일 자주 하는 말이 이것인데, 기다리면 답이 나오는 질문과 이 규모로는 답이 안 나오는 질문을 똑같이 취급했습니다. 관측된 차이가 유지된다고 두고 유의(α=.05)·**검정력 80%**에 닿는 데 필요한 추가 판수를 계산해 붙였습니다.

| 관찰 | 우연일 확률 | 갈리기까지 |
| --- | --- | --- |
| 원딜은 다른 라인보다 낮습니다 | 5% | **약 70판 더** |
| 한 세션에서 뒤로 갈수록 낮습니다 | 11% | **약 175판 더** |
| 상대 입력이 많은 판의 승률이 높습니다 | 11% | **약 250판 더** |
| 최근 40판의 6%p 낙폭 자체 | 46% | **1200판 넘게** — 사실상 답 없음 |

## 고칠 것처럼 보였지만 근거가 없어 그대로 둔 것

v11에서 미뤄둔 항목 두 개를 실측했습니다.

- **팀·상성 축의 이진 가중치 게이트** — 입력량 비례 방식 네 가지를 prequential AUC로 비교했더니 전부 더 나빴고(0.5736 → 0.570~0.573), 겨냥한 구간인 적 1~2명 입력 판에서 특히 나빠졌습니다(0.624 → 0.578~0.608). **좋아진다는 근거가 없어 건드리지 않습니다**
- **첫 픽 감점의 수동 숙련도 면제** — 면제가 정당해 보이는 관측(53% vs 33%)이 있지만 챔폭이 현재 시점 스냅샷이라 사후 오염이 섞여 있고 p=0.20입니다. 오염된 관측으로 엔진을 고칠 수는 없습니다

## 검증

| | v11.0 | v12.0 |
| --- | --- | --- |
| 199판 재채점 시 점수가 달라진 판 | — | **0판 / 199판** |
| 슬럼프에 "무엇이 달라졌나"를 답하는가 | 못 함 | **7개 항목 검정 + 보정** |
| 확정되지 않은 관찰에 필요 표본 제시 | 0건 | **전부** |
| 근거 없이 바꾼 엔진 파라미터 | 0개 | **0개** |

**엔진 점수는 한 점도 건드리지 않았습니다.** v11과 v12로 199판을 각각 다시 채점해 총점·신뢰도가 전부 일치하는 것을 확인했습니다.

기존 전적·챔폭·가중치는 그대로 유지되며 별도 마이그레이션이 필요 없습니다.

서비스 워커 캐시로 이전 버전이 보이면 화면 상단의 업데이트 알림을 누르거나 한 번 강력 새로고침하세요.
