# WR Picker v11.0.0 대규모 개선 패치

전체 기능과 실행·검증 방법은 [README.md](README.md)를 참고하세요.

이번 패치의 주제는 **앱이 하는 말을 근거에 맞추는 것**, 그리고 **데이터를 잃지 않는 것**입니다. 검증은 실사용 전적 199판으로, 각 판을 그 판 직전까지의 정보만으로 다시 채점해서 했습니다.

## 앱이 자기 측정을 소표본으로 단정하고 있었다

- v10은 상성 축 0.47을 근거로 "방향이 뒤집혔다"고 말하고 가중치까지 조정했습니다. 그 값의 오차는 **±0.04**였고, **네 축 전부 95% 구간이 0.50을 걸칩니다** — 지금 전적으로는 어느 축도 동전던지기와 구분되지 않습니다
- 축별 성적표에 **오차막대와 0.50 기준선**을 그리고, 자동 보정을 **경험적 베이즈**로 바꿔 측정 오차만큼 0.50 쪽으로 당긴 뒤 적용합니다
- 분석 탭의 승률 조언에 **2표본 검정 + 다중 비교 보정**을 붙였습니다. 단정형 조언 7건 → **3건**, 나머지는 `아직 판단할 수 없는 관찰`로 내렸습니다("상대 픽을 끝까지 입력하세요"는 우연일 확률 11%였습니다)
- 게이트는 **fail-closed**입니다 — 승률 추론인데 p가 없으면 단정형으로 올라가지 않습니다
- `원딜 — 서폿 유무별` 카드의 교란을 드러냅니다('서폿류 없음'은 대체로 아군을 덜 입력한 판이었습니다)

## 저장된 전적이 한 번 깨지면 전부 사라졌다

브라우저에서 재현했습니다 — 저장값 끝 40바이트가 잘리면 **200판이 0판**이 되고, 부팅 루틴이 손상된 원본까지 덮어써 복구가 불가능했습니다. 자동 백업 파일도 같이 비워집니다.

- 읽기에 실패하면 **원본을 먼저 격리**하고, 잘린 JSON에서 **마지막 온전한 판까지 되살립니다**(200 → 201/202판 복구)
- 확인 전까지 시드로 덮지 않고 백업 파일도 건드리지 않습니다
- ISO 문자열 시각을 가진 백업이 **10판 → 2판**으로 붕괴하던 것, 성과 등급이 **엉뚱한 판에 기록**되던 것, 되돌리기 스냅샷이 서로를 덮어쓰던 것, 챔폭 항목이 조용히 버려지던 것도 함께 고쳤습니다

## 라인 상대를 29%에서 모르는 건 입력 문제였다

56판 전수 분석 결과 **전부 그 라인에 설 수 있는 적이 아예 입력되지 않은 판**이었습니다. 적 5명을 다 넣으면 97%에서 찾습니다.

- 상대팀 아래에 **5라인 배정 격자**를 놓아 빈 라인이 한눈에 보이게 했습니다
- 빈 칸을 누르면 **그 라인 챔만 걸러진 검색**이 바로 열립니다

## 검증

| | v10.0 | v11.0 |
| --- | --- | --- |
| 총점 순위 일치도 | 0.576 | **0.580** |
| 통계적 근거 없는 단정형 조언 | 4건 | **0건** |
| 저장값 손상 시 남는 판(200판 기준) | **0판** | **201판** |
| ISO 백업 10판 복원 | **2판** | **10판** |

엔진 점수 변화는 작습니다(판당 평균 0.32점). 점수를 올리는 패치가 아니라, **말을 근거에 맞추고 데이터를 지키는 패치**입니다.

기존 전적·챔폭·가중치는 그대로 유지되며 별도 마이그레이션이 필요 없습니다.

서비스 워커 캐시로 이전 버전이 보이면 화면 상단의 업데이트 알림을 누르거나 한 번 강력 새로고침하세요.
