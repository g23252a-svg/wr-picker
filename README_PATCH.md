# WR Picker v18.0.0 패치

전체 기능과 실행·검증 방법은 [README.md](README.md)를 참고하세요.

요청: *"추천 1순위 대신 익숙한 챔 밀어주게 엔진도 고쳐줘."* 실사용 **271판**(~09-22)으로 **먼저 쟀습니다.**

## 1. 재보니 엔진 점수를 바꿀 근거가 없었다

| 잰 것 | 결과 |
| --- | --- |
| 숙련 판수만으로 승패 맞히기 | **순위 일치도 0.4988** (동전던지기) |
| 판수 구간별 승률 | 0판 40% · 1~2판 63% · 3~5판 52% · 6~10판 56% · 11판+ 44% (**단조가 아님**) |
| 숙련 가중치 ×1.3 / ×1.8 / 근거 하한 0.70 | 0.5560 / 0.5562 / 0.5577 (현재 **0.5565**, 오차 ±0.035) |
| 판수 보너스를 점수에 더하기 | **0.5386 — 지금보다 나쁨** |

**점수 공식을 바꿀 근거는 이 전적 어디에도 없었습니다.**

## 2. 그래서 점수가 아니라 순서만 바꿉니다

v17이 찾아낸 **실제로 이겼을 때의 행동**을 그대로 옮겼습니다 — 이탈한 15판의 픽은 점수가 오히려 낮았고(59.0 vs 61.4) 대신 더 많이 해본 챔이었습니다(7.2 vs 5.4). **평균 2.4점을 손해 보고 익숙한 쪽으로 갔습니다.**

- 설정의 **손에 익은 픽 우선**(기본 **꺼짐**) → 1순위와 **3점 이내** 후보 중 가장 많이 해본 챔이 위로
- **점수는 한 자리도 안 바뀝니다.** 271판 재채점 전부 v16·v17과 동일(0판 차이)
- 3점은 실측 이탈 비용 2.4점에서 왔습니다. 더 넓히면 '추천'이 아니라 '내 챔폭 정렬'입니다

| 서폿 | 1·2·3순위 |
| --- | --- |
| 끔 | 말파이트(61.1·15판) · 소나(60.7·9판) · 갈리오(58.7·26판) |
| 켬 | **갈리오(58.7·26판)** · 말파이트(61.1·15판) · 소나(60.7·9판) |

나머지 네 라인은 1순위가 3점 넘게 앞서 **그대로입니다.**

## 3. 화면이 거짓말하지 않게 같이 고친 것

- 배지 **"종합 1순위"** → 재정렬됐으면 **"손에 익은 픽 · −2.5점"** (감수한 점수를 숫자로)
- 리본 **"BEST"**(CSS) → 재정렬됐으면 **"MY PICK"**. 배지만 고치면 같은 카드가 두 가지 말을 합니다
- v17 순응도 분석에서 '1순위'의 뜻이 말없이 달라짐 → `familiarFirst`를 판마다 기록하고 섞인 판수를 카드에 밝힘

## 4. 근거가 약하다는 말을 설정 화면에 적었습니다

이탈 80%는 **벗어나기로 고른 판**이라 편향이 크고, 숙련 판수 자체는 승패를 못 갈랐고(0.50), 가중치 설계 4종도 전부 오차 안이었다는 사실을 켜기 전에 읽게 했습니다.
