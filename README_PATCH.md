# WR Picker v14.0.0 패치 · 게임 패치 7.2e

전체 기능과 실행·검증 방법은 [README.md](README.md)를 참고하세요.

실사용 전적 **258판**(2026-07-03 ~ 09-11)에서 최근 16판이 **12승 4패(75%)**로 올라왔고, v13 카드를 여기에 걸자 두 곳이 깨졌습니다.

## 1. 상승을 "낙폭"이라고 불렀다

v13은 여러 창을 훑어 신호가 가장 강한 구간을 고르는데, 그 구간이 **잘 나가는 구간**일 수도 있습니다. 문구가 전부 슬럼프 전제라 최근 16판 75%(**+23%p**)를 골라 놓고 *"이 정도 낙폭은…"*이라고 말했습니다.

- 방향(`up`/`down`/`flat`)을 먼저 읽고 문구를 고릅니다. 제목은 `최근 폼 진단`
- 유의한 상승에는 전용 문장과 파란 색을 줍니다 — 경고색은 내려갈 때만
- 조사를 낱말에 붙여 들고 다닙니다. v14 초안이 **"상승폭는"**을 출력했습니다
- 곡선 설명도 고쳤습니다 — 고른 건 "가장 낮은 구간"이 아니라 **전체 평균과 가장 크게 벌어진 구간**

## 2. 라인 비중이 '늘면 나쁘다'로 못박혀 있었다

원딜 비중 **14% → 50% (+36%p, 우연 1% 미만)**가 "나쁜 변화"로 올라왔는데, **그 구간 원딜은 7승 1패**였습니다. 통산 43%로 가장 낮은 라인이라는 이유만으로 잘 되는 변화를 경고한 셈입니다.

- 방향을 **그 창에서의 실제 성적**으로 정합니다
- 나쁘지 않은 변화에도 근거 숫자를 싣습니다(`그 구간 원딜 7승 1패`)
