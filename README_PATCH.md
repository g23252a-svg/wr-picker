# WR Picker v10.0.0 대규모 개선 패치

전체 기능과 실행·검증 방법은 [README.md](README.md)를 참고하세요.

이번 패치의 주제는 **엔진이 자기 자신을 정직하게 채점하게 만드는 것**입니다.

- v9의 성적표는 판마다 저장해둔 옛 점수를 채점하고 있었습니다(111판에 아홉 개 엔진 버전이 섞여 있었고 32판은 아예 빠져 있었습니다). 이제 **과거 전 판을 지금 엔진으로, 그 판 직전까지의 전적만 보고 다시 채점**합니다
- **축별 성적표**를 냅니다. 상성 축의 순위 일치도는 0.41 — 방향이 뒤집혀 있었습니다
- 그래서 **못 맞히는 축의 발언권을 자동으로 깎습니다**(최대 −50%). 설정에서 끌 수 있고, 적용값은 숫자로 그대로 보여줍니다
- **라인 상성 축의 상한**을 씌웠습니다(최대 기여 +36 → +16). 봇 듀오는 1v1 라인이 아니므로 정글처럼 감쇠합니다
- 가이드 카운터 관계의 **라인 태그**를 이제 실제로 씁니다 — 서폿 럭스의 카운터 목록이 미드 럭스에게 적용되지 않습니다
- **분석 탭의 막대가 v7.1 이후 한 번도 그려지지 않고 있었습니다**(인라인 span에는 `width`가 적용되지 않습니다). 고쳤습니다

기존 전적·챔폭·가중치는 그대로 유지되며 별도 마이그레이션이 필요 없습니다. 자동 축 보정은 켜진 상태로 시작하고, 축마다 30판이 모이기 전에는 아무것도 바꾸지 않습니다.

서비스 워커 캐시로 이전 버전이 보이면 화면 상단의 업데이트 알림을 누르거나 한 번 강력 새로고침하세요.
