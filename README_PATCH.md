# WR Picker v17.0.0 패치

전체 기능과 실행·검증 방법은 [README.md](README.md)를 참고하세요.

실사용 **271판**(~09-22, 마지막 13판 4승 9패·끝에 6연패)으로 검증했습니다.

## 1. 판마다 top3를 저장해 두고 한 번도 쓰지 않았다

v10부터 '엔진 자기 검증'을 해왔지만 가장 직접적인 질문은 안 물었습니다 — **추천대로 골랐을 때와 아닐 때 결과가 달랐는가.**

| | 승률 |
| --- | --- |
| 1순위 그대로 | **50%** (234판) |
| 다른 챔 선택 | **80%** (15판) |
| | 우연일 확률 **2%** |

불편한 숫자라 **교란을 같이 싣습니다**: 이탈은 이유가 있을 때만 하는 행동이라 표본이 기울어 있고(15판), 이탈한 판의 픽은 **엔진 점수가 더 낮았습니다**(59.0 vs 61.4). 입력량·신뢰도는 양쪽이 같았습니다. 달랐던 건 하나 — **그 챔으로 해본 판수 7.2판 vs 5.4판**.

기계가 아니라 손이 이긴 쪽에 가깝고, 이 앱의 유일한 단정형 조언(처음 잡는 챔 줄이기)과 같은 방향입니다.

- 양쪽 `MIN_BUCKET` 이상일 때만, 유의할 때만 단정형
- 손에 익은 정도는 그 판 시점까지로 셉니다(사후편향 차단)

## 2. 성과 축이 한쪽만 재고 양쪽을 다 본 것처럼 말했다

`enough` 게이트가 전체 기록 판수만 봐서, 이긴 판이 1판인 연패 구간에도 *"같은 결과의 판끼리 비교하면 성과는 그대로"*라고 말했습니다.

- `testedLost`/`testedWon`을 기록하고 못 잰 쪽은 **(표본 부족)** 표시
- 한쪽만 쟀으면 그렇게 말합니다
- 초안이 없는 필드(`f.won.n`)를 읽어 **"undefined판뿐"**을 출력했고 테스트로 막았습니다
